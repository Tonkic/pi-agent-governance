      怎么使用这个项目？
      1. 初始化当前项目，保留已有 README / AGENTS。
      2. 由人明确目标、范围和验收条件，创建任务。
      3. Agent 按 STATE 执行；写入型子任务使用独立 Git worktree。
      4. 更新进度 → 审查差异 → 实际测试 → 验证 → 关闭任务。

      面板不执行测试，也不自动提交、合并或推送。Git 操作由 Agent 使用 governance 工具完成。
