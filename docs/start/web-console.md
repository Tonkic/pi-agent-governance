# 统一浏览器工作台

Antigravity、PI-Desktop、Codex、Claude Code 和 Pi 共用同一个只读浏览器工作台。你在浏览器查看项目全局状态，在原 AI 会话里开发和维护文档。

## 从宿主打开

- **MCP 宿主（Antigravity / Codex / Claude / Pi）**：配置 [本地 stdio 连接](mcp.md) 后，在会话中请求打开工作台（调用 `governance_ui`：`{"action":"open","confirmed":true}`）。
- **PI-Desktop**：安装插件并授权后，按 **Alt+空格** 搜索“Agent 项目治理”，或从**右侧工作面板插件列表**打开“项目治理工作台”点击打开；也可按 **Ctrl+Shift+P** 直接启动。
- **查询或关闭**：`{"action":"status"}` 只读查询状态（不启动服务）；`{"action":"close","confirmed":true}` 关闭当前服务。

工作台固定绑定宿主当前核实的项目目录，不接受外部传入路径、端口或 URL。完整私有链接直接交给系统浏览器，凭据存入标签页 `sessionStorage` 后立即从地址栏移除，请勿分享链接或转发端口。

## 生命周期与切换

- **同项目复用**：重复打开同一项目会复用已有本地服务。
- **切换即回收**：切换工作区、卸载插件或断开 MCP 时，立即关闭旧服务并撤销旧页面访问权。
- **自动租约**：页面每 15 秒发送心跳（TTL 120 秒）；所有标签页关闭后约 5 秒自动释放端口（首次启动 65 秒内无页面连接亦自动回收）。SSH/WSL 等远程环境不支持自动拉起宿主机本地浏览器。

## 手动独立启动

需 Node.js 22+ 与 Git。在仓库构建后（或通用包解压执行 `npm ci --omit=dev --ignore-scripts` 后）运行：

```powershell
node build/web/server.js --workspace D:/projects/example
node build/web/server.js --workspace D:/projects/example --port 4719  # 可选指定端口
```

复制终端输出的完整私有地址到浏览器打开，按 `Ctrl+C` 停止服务。独立模式不自动初始化项目，也不按页面租约自动退出。

## 四大只读页面

- **工作台**：顶部展示任务指标微图与完成度环，下方三栏呈现待办、进行中、已完成卡片。点击卡片查看详情，「查看全部」检索全部完成历史。
- **项目架构**：切换查看源码指纹图、架构设计方案/ASCII 与任务状态流；支持缩放、平移与上下游调用追踪。
- **Git**：固定 `main` 主轴居中展示提交图；悬停查看提交摘要，点击打开父提交与文件差异弹窗。详见 [提交图](../guides/git.md#浏览器提交图)。
- **项目文档**：按目录分类阅读 Markdown 文档，无独立“行为文档”重复页。

桌面端左侧默认收起为 `64px` 图标栏，悬停或键盘聚焦时平滑展开覆盖，不挤压正文；窄屏自动切换顶部紧凑导航。低频说明收纳在 `?` 浮层按钮中，悬停或点击即可查看。

## 项目文档阅读

只读扫描根目录说明（`README.md`、`AGENTS.md`、`CHANGELOG.md`、`CONTRIBUTING.md`、`LICENSE.md`）及 `docs/`、`notes/` 下的 `.md` 文件：

- **分类与选读**：左栏按 `项目入口 / 快速开始 / 协作工作流 / 架构与参考 / 开发与交付`（或业务域目录）分组显示中文标题与路径，默认折叠 `notes/archive/`；未选文档时正中展示四象限选读卡片。
- **排版与交互**：支持 `16px–20px` 字号调节、专注模式、实时阅读进度条、本页目录跟随高亮，以及标题/文件名双搜索。
- **安全渲染**：内部相对链接（如 `[开发](../ops/development.md)`、`../../README.md`、`#标题`）在阅读器内无刷新跳转；HTML、图片与外部链接仅按纯文本展示，不加载外部资源或执行脚本。
- **读取限额**：最多扫描 8 层目录、4000 个条目、500 个文件，单文件上限 256 KiB（超 4000 行自动降级纯文本保证流畅）。

## 安全边界

- 服务仅监听 `127.0.0.1`，强制校验精确 `Host`、`Origin` 与一次性会话令牌，拒绝所有项目/看板/设计写入请求（单请求上限 1 MiB，8 并发）。
- 外部会话修改项目后，点击页面 **「刷新」** 读取最新快照；离线时仍可浏览已加载正文。
