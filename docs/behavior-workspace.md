# 切换与只读项目

所有宿主使用固定项目的只读工作台。PI切换工作区撤销旧服务，需重新请求打开；MCP绑定启动项目，切换后重建连接。不猜“最近项目”。

### WS-001 — 切换后显示新项目

明确打开新项目后显示其路径和数据；旧服务撤销，旧页不重定向。迟到的旧快照不得覆盖新项目。未初始化项目仅查看已有资料，不显示启用按钮、不自动创建治理文件；初始化在原AI客户端执行。

### WS-002 — 外部更新手动读取

用户在原AI CLI/应用更新后，工作台手动刷新读取。旧项目的迟到读取不得改变新项目的内容、提示或焦点；不自动重放操作。

### WS-003 — 工作台没有项目写入

看板只提供搜索、详情、历史与浏览。没有新建、编辑、移动、拖动、长按/右键操作菜单或表单草稿；渲染器、桥接与HTTP拒绝项目/设计写入及Agent控制，不因confirmed:true放行。切换立即关闭旧详情，不带入新项目。

## 验证边界

关联检查使用隔离Chromium、临时项目和模拟宿主事件；实际HTTP拒绝及MCP更新另有回归。它们不证明已安装宿主、物理触屏或SSH远端通过。检查机制留在开发流程，不另设“行为文档”页，见[开发检查](doc-driven.md)。

Docs说明当前功能与架构，Notes仅按需追溯；修改说明不是新任务授权，范围仍以STATE为准。
