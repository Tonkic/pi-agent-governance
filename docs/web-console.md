# 统一浏览器工作台

PI-Desktop、Codex、Claude Code和Pi共用同一个浏览器界面、治理核心与项目文件。不再区分PI内嵌面板和CLI页面。宿主是项目连接器，原会话继续负责开发/分析；网页不是Agent或模型遥控器。

## 从宿主打开

- PI-Desktop：安装并授予入口权限后，Alt+空格搜索“Agent 项目治理”，或右侧工作面板插件列表选“项目治理工作台”，再点“打开浏览器工作台”。两个位置共用轻量入口页；Ctrl+Shift+P命令仍直接打开，不经过入口页。
- MCP宿主：配置 [本地stdio连接](mcp.md)，在原会话明确请求打开工作台，调用 `governance_ui`：`{"action":"open","confirmed":true}`。
- 状态：`{"action":"status"}` 不启动服务；关闭：`{"action":"close","confirmed":true}`。工具不接受项目路径、URL、端口或租约参数。

PI工具以可信调用会话绑定项目，不跟随其它前台聊天；命令读取宿主当前可见项目。Claude MCP可从官方CLAUDE_PROJECT_DIR绑定启动项目；普通Codex/Pi MCP使用配置的绝对项目。缺失/不支持身份或生命周期接口时拒绝，不猜最近项目、cwd或home。

只打开本次服务生成的127.0.0.1私有地址。完整链接直接交给系统浏览器，不进入工具结果、聊天、日志或会话注册表；结果只包含项目、origin和状态。浏览器将片段凭据读入标签页sessionStorage并移出地址栏；不要分享/截图/提交完整链接。浏览器存储的清理行为由浏览器管理，重开服务需重新请求打开。

PI的shell.openExternal仍仅打开生成链接。经用户明确批准，ui.panel/ui.view只挂载同一入口页，显示项目状态、手动刷新和打开按钮，无业务看板/聊天。加载/恢复/view:open不自动打开，切换后旧按钮失效；状态版本绑定项目与插件代次，点击前后重核对。入口不接收路径/URL、不返回私有地址，也不修改项目数据。desktop.control只核实调用元数据；无models.list，安装权限仍需人工确认。

“侧边栏入口”指右侧工作面板的插件视图列表，不是左侧聊天/项目栏。入口对应官方ui.panel/contributes.views（ui.view），不是renderer注入或宿主改造；所需支持依宿主版本。没显示时检查启用、权限及激活范围。

## 生命周期与切换

- 每个宿主连接器只拥有一个服务。同项目重复打开复用服务，可能打开另一个标签页，不承诺通用“聚焦已有标签页”。
- 切换项目先关闭旧服务，再创建新服务。PI收到workspace:changed即撤销旧能力，需重新明确打开；旧页面不会自动改绑到新项目。原项目草稿仅留在旧标签页内存，可复制，不自动提交到新项目。
- 页面使用有界租约：心跳15秒、TTL120秒；首次无页面约65秒回收。最后页面离开或过期后至少5秒宽限，支持刷新/多标签页/bfcache；后台冻结可能导致到期，重新请求打开即可。
- 显式关闭、PI卸载或MCP断开撤销在途打开并清理自有服务。只关闭自己拥有的连接/短命打开器，不终止浏览器或其它进程。崩溃时由进程退出释放端口；不另设常驻桌面进程。

已知SSH/WSL/远程容器环境拒绝系统自动打开；远程localhost不等于用户本机。未支持的宿主/version需报告限制，不能通过私有数据库、隐藏IPC或端口转发冒充本机体验。

## 手动独立启动

需要Node.js 22+和Git。开发仓库先 `npm ci`、`npm run build`；通用包解压后 `npm ci --omit=dev --ignore-scripts`。

```powershell
node build/web/server.js --workspace D:/projects/example
# 可选端口；0为随机空闲端口
node build/web/server.js --workspace D:/projects/example --port 4719
```

只有人工CLI会在终端输出完整私有地址；手动打开，不分享。该独立模式不归宿主连接器管理、不按页面租约退出，Ctrl+C停止。启动不自动初始化项目、打开浏览器或调用Agent。

`--workspace`必须为已存在的绝对非链接目录，没有默认cwd；服务固定绑定一个项目。首次启用仍需确认，不自动迁移数据。

## 可执行的操作

- 看板：新建、编辑、三栏移动、搜索和完成历史，沿用键盘/拖动与确认。
- 项目：查看STATE、开始明确任务、更新进展/下一步/阻塞，不提供任意命令或Git写入。
- 源码图：查看与来源核对；更新由原宿主通过治理工具保存，不把设计写成源码事实。
- 设计：明确发起草案/修订，原宿主保存proposal；浏览器刷新后审阅ASCII/画板/差异，人工确认或放弃。确认不授权实施或证明测试通过。
- 行为文档：一级页面 `#behaviors-section`，按需读取绑定正文与实际本机证据，支持直接链接与前进/后退；缺失或过期时如实显示。
- Git：只读真实提交图，main第一父链固定居中；默认仅主轴/分支两项图例和主轴/HEAD标记，其他分支名/标签/归属移到悬停或聚焦摘要，不铺长列表。点击打开提交及文件差异弹窗，关闭回原节点。已删除受管网页与自动登记查询，真实Git数据保留。首次按需批量读取，手动刷新，不联网或执行Git写入，见[提交图](git.md#浏览器提交图)。
- 项目文档：左导航进入文档库，搜索文件名、选择正文，使用本页目录跳转标题；外部修改后点“刷新文档”。与“行为文档”的证据视图分开。

0.8.3的看板、架构、Git、项目文档和行为文档共用导航、顶部栏和页面标题。桌面默认64px图标栏，鼠标移入或键盘聚焦时覆盖展开至212px，不挤动正文；鼠标选页后收起，键盘保留焦点。移出后收起，无切换按钮或持久展开偏好。窄屏使用可直接点击的五项紧凑导航；无悬停能力的宽屏保留可见文字导航。

行为页首次进入才读取，切页返回复用当前内容；“刷新行为文档”手动重读。离线或读取失败保留已有正文，不自动重试；项目刷新/切换清空旧内容并拒绝迟到结果。仅展示正文、来源和六类证据状态，不执行HTML、远程资源或测试，不写STATE。文档页的长连接说明默认折叠，可手动展开；其他页保持原有显示。

欢迎/真实统计、三栏卡片与项目摘要保留，支持双语明暗。装饰不代表操作记录，统计不证明功能或测试通过；不会开放网页Agent、模型、Git写入或后台轮询。

页面隐藏宿主分析/模型/会话按钮，HTTP也拒绝 `governance.operation`、Agent/model/session及任意Git写入。使用原会话已有上下文和模型，不再从页面选择或创建聊天。

## 项目文档阅读

只读范围为根目录 `README.md`、`AGENTS.md`、`CHANGELOG.md`、`CONTRIBUTING.md`、`LICENSE.md`，以及 `docs/`、`notes/` 下的 `.md`。未初始化也可读取已有文档；不写入STATE、锁或缓存。

仅扫描至8层、4000个条目、最多500个文件；单文件最多256 KiB。达到限制会明确提示，不代表全仓库搜索。敏感/隐藏/越界路径、符号链接/junction、非普通文件、非UTF-8及过大文件被拒绝或不列出。文件名限制不是正文秘密扫描，请只在可信项目中使用。

文档仅在内容区适配：默认18px系统无衬线、舒适行距与受控行宽，无远程字体。文件库和本页目录按可用内容宽度折叠，选文档或标题后回到正文；文档工具在统一操作区调整字号、切换专注阅读或刷新。专注仅隐藏局部文件库/目录，不隐藏全局导航与顶部栏。显示设置只在页面内存，不写项目或浏览器持久存储。

正文支持标题、段落、粗体/斜体/删除线、行内代码、嵌套列表、只读任务标记、连续引用、表格和代码围栏；表格/长代码局部横滚，软换行按正文自然衔接。HTML、外部链接和图片保留文本，不执行脚本或加载资源。复杂Markdown不保证完整排版，超过4000行或节点预算改为纯文本，标题目录最多200项。

`[开发](development.md)` 等相对Markdown链接按当前文档目录解析，只跳到已列出的受限文档；根README中则写 `docs/development.md`，`../README.md` 可返回根说明。支持 `#标题`、跨文件标题与中文百分号编码；重复标题依次加 `-1`、`-2`。内部跳转保持工作台路由，键盘Enter可用，不把正文路径作为浏览器URL。缺失/越界/隐藏/外部/脚本/查询参数链接不激活；未找到标题时提示，不自动重试。离线仅允许当前正文的标题定位，不发起文件读取。

按需加载列表与选中正文，不轮询/预读全部文件；离线保留当前正文和本地筛选，重新连接后手动刷新。切换项目清空内容，迟到结果不能覆盖新选择；没有编辑、上传、下载或命令执行功能。

## 共享数据与安全

各入口须绑定同一个绝对项目。网页/客户端写入后另一端重读快照；修订、草案ID、指纹和锁仍有效。过期写入拒绝，不自动重放。MCP仍为stdio，不把浏览器HTTP冒充MCP传输。

- API验证精确Host、同源Origin、随机凭据和JSON；无CORS放行，固定动作/静态资源清单，不能下载任意项目文件。
- 请求体1MiB、8并发、32连接，时间有界；沿用确认/最新修订/范围/路径保护。错误不回显参数、Git输出或堆栈。
- 禁止嵌入、跨源连接和缓存，无第三方CDN或远程模型调用。不要转发端口或配置公网/局域网代理。
- 本机进程或浏览器扩展仍可能读取数据/凭据；这是可信仓库工具，不是操作系统或恶意并发沙箱。

服务关闭/过期后重新从宿主明确打开；写入失败先重读状态、范围、锁与修订，不盲目重试。端口占用报错，不终止其它进程。自动SDK/VM/HTTP测试不等于真实安装客户端的完整验证。
