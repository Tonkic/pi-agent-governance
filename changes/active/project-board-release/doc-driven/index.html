WS-001 · 切换后显示新项目

打开另一个项目后，面板显示新项目的路径和数据。旧项目尚未返回的读取结果，不得覆盖新项目。 新项目尚未启用治理时，选择「启用当前项目治理」，再确认初始化。取消确认不会创建治理文件。切换项目不会自动初始化。

WS-002 · 旧保存不影响新项目

切换项目后，旧项目保存产生的迟到结果，不得改变新项目的提示、焦点或工作项内容。旧项目的「新建工作项」动作，也不得在新项目重新打开弹窗。 这不表示已经提交的保存会被撤销；保存结果属于原项目，不会自动在新项目重放。

WS-003 · 草稿按原项目隔离

切换项目时，旧确认窗口关闭，未保存的表单草稿按原项目隔离保留。选择「保留的草稿」可查看并复制内容，手动恢复。 草稿不自动保存到磁盘，不自动恢复或提交到新项目。关闭面板后，内存中的草稿不再保留。本阶段关联的测试检查切换时隔离和取消确认，不单独证明关闭进程后的生命周期。
