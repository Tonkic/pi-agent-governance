# 0.8.1：统一壳层与可收起导航

## 授权与目标

用户指出进入文档页后整套布局变化割裂，明确批准统一原工作台框架、侧栏可收起以保证阅读体验；另确认交付 **0.8.1补丁**，仅源码及官方安装包，无标签/GitHub Release/市场/npm/自动安装。

| Before | After（本项目标） | Why |
| --- | --- | --- |
| 文档页改排全局导航并隐藏顶部栏 | 文档、看板、架构、Git共用同一壳层 | 切页不再像切换应用 |
| 全局导航固定占空间 | 可手动展开/收起并跨页保持选择 | 把空间还给正文与画布 |
| 文档另有重复标题和返回工具区 | 统一页面标题，文档仅保留局部工具 | 减少重复与视觉干扰 |
| 阅读优化与管理框架二选一 | 保留18px/1.8/受控行宽及局部库/目录 | 不牺牲已改好的阅读排版 |

全局侧栏选择只保存在当前页面内存，不写项目或浏览器持久存储；切页、项目刷新、主题与离线恢复不应覆盖用户选择。窄屏必须始终有可恢复导航的按钮，不把正文挤成窄条。专注阅读只影响文档局部辅助区，不自动切换全局壳层。

原只读文档、Markdown/HTML资源不执行、路径/敏感/链接/UTF-8/扫描读取限额、epoch/root/request/ownership保护、看板历史与确认草稿/架构操作保持。不增加依赖/权限、宿主会话或模型功能，不恢复暂停桌面。

## 版本侧实际检查

package及lock两处本包版本一致改为0.8.1，当前说明与生成manifest随构建更新；历史0.8.0证据保留。版本一致性与不发布政策测试对应更新，依赖锁未升级。

干净npm ci、typecheck/build与版本侧完整npm test实际通过：208测试、零失败/跳过；不把此基线结果冒充最终界面验收。

## 进度

界面在独立受管worker实现。功能、实际视觉证据、合并后完整回归、官方包/分发与main/双OS CI完成后持续更新本文件；看板doing，原总任务working及历史阻塞保留。
