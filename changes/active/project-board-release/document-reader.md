## 实现与边界

- `documents.ts`：固定五个根说明Markdown及docs/notes下小写.md；list只返元数据、read有界句柄读取，未初始化亦可用，不写STATE/锁/缓存。
- 严格schema、项目断言、绝对非链接根、逐组件路径和真实大小写、敏感/隐藏/越界/编码混淆拒绝；普通文件、fatal UTF-8、二进制控制字符和读取变化校验。
- 固定限额：500文件、4000扫描节点、8层（含目录与文件名）、单文件256KiB；排序、truncated提示。list不验证正文编码，read时验证。
- `governance.documents`仅list/read，经原HTTP认证/白名单；不提供任意静态文件、Agent/模型/Git命令、编辑/上传/下载。
- 独立renderer模块与CSS沿用第一项主题。文件名本地过滤、正文、标题目录和显式刷新；不预读正文、不轮询/自动重试。HTML、链接和图片均literal，不装载资源。
- Markdown子集：标题/段落/粗体/行内代码/列表/引用/围栏；超过4000行纯文本、目录最多200项。不是完整Markdown引擎，不扫描正文中的秘密，可信项目边界不变。
- epoch/root/请求序号保护选择和项目切换；离线保留当前正文，项目切换/页面离开清空。全局刷新临时清空snapshot不遗留pending。
- 固定构建与分发清单增加模块和资源，无依赖/权限/版本变化；轻量PI入口与浏览器业务单一界面不变。
