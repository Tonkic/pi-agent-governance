## Migration / 迁移

This is a first installation under a new ID, not an automatic upgrade from `pi.agent-governance`. Back up STATE and `.governance/`, disable the old instance, install the community plugin and grant its permissions. Keep old packages for rollback. Future updates use the host marketplace mechanism after approval and catalog publication.

新 ID 需要首次安装和重新授权；先停用旧插件，避免工具与命令重复。保留项目 STATE、`.governance/` 与旧安装包，不删除用户数据。审核上架后的同 ID 升级使用宿主更新机制。
