## 目标与边界

| Before | After（本项目标） | Why |
| --- | --- | --- |
| 阅读前先穿过顶部管理提示 | 阅读页独立紧凑工具区，其他管理页面保持 | 正文先进入视线 |
| 14px正文和被侧栏挤压的行宽 | 系统无衬线、17–18px默认字号、受控行宽和段落间距 | 连续长文更舒适 |
| 手机先滚过文件库与目录 | 文件库/目录按需展开，正文优先 | 降低操作和滚动成本 |
| 技术Markdown表格等纯文本杂乱 | 补安全常用格式与局部横滚 | 不以可执行HTML换取排版 |

只读固定文档范围、路径/敏感/链接保护、256KiB/500文件/4000条目/8层限额、原HTML/链接/图片字面文本不执行和epoch/request/owns迟到保护保持。无依赖/权限或宿主会话/模型能力变化；不恢复暂停的桌面开发。
